# ARC Raiders 復帰勢攻略

半年ぶりにARC Raidersへ戻った人向けの、非公式ファンガイドです。凍った道 2.0（Frozen Trail）で変わったスキルツリー、ペンドラ・パス、装備の作り方、前哨基地、武器メタ、新敵を、海外ソースの引用付きで整理しています。

## 公開URL

https://yokaroumon44-coder.github.io/arc-raiders-guide/

## 内容

- ペンドラ・パス素材マップ
- 新システム解説
- おすすめスキルツリー（レベル別の振り方・公式アイコン付き）
- 普段装備と作り方
- 素材・武器画像の拡大表示（武器は作成フロー付き）
- 前哨基地
- ワークショップ強化素材
- 武器メタ・ティア表
- 新敵・フリゲート対策
- 引用元一覧

## ローカル確認

`index.html` をブラウザで開くだけで表示できます。画像はすべて `assets/` 内にローカル保存しています。
